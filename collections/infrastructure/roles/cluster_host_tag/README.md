# cluster_host_tag

## Description

This role writes two small marker files on the host it runs against, recording that a playbook
push happened and which inventory state it was pushed from. It is appended as the last role of
every playbook generated by the `bluebanquise-cluster-playbooks-daemon` (part of the
`cluster_playbooks` role) - it is not a function profile and is not meant to be attached to a
function group via `bluebanquise-playbook add`.

Supported distributions: RHEL 9/10, Ubuntu 24.04/26.04, Debian 13, OpenSuse Leap 16.

## Instructions

Not meant to be run standalone or added to a playbook by hand - it requires
`cluster_host_tag_inventory_checksum` to be passed as an extra variable, which only the
`bluebanquise-cluster-playbooks-daemon` does today:

```yaml
- hosts: fn_workers
  roles:
    - bluebanquise.infrastructure.nfs
    - role: bluebanquise.infrastructure.cluster_host_tag
```

```bash
ansible-playbook fn_workers.yml -i inventory --limit c001,c002 \
  -e cluster_host_tag_inventory_checksum=<sha256sum> \
  -e cluster_host_tag_path=/etc/bluebanquise/tags
```

Running it without `cluster_host_tag_inventory_checksum` defined fails immediately with a clear
assertion error rather than silently writing an empty or undefined tag file.

## Output files

```
/etc/bluebanquise/tags/
  inventory              # the checksum value passed in cluster_host_tag_inventory_checksum
  last_ansible-playbook  # ISO 8601 timestamp of this playbook execution (ansible_facts.date_time.iso8601)
```

`bluebanquise-cluster-playbooks-daemon` reads `inventory` back over SSH on its next cycle to
decide whether this host is up to date with the current inventory state.

## Variables

| Variable | Default | Description |
|----------|---------|--------------|
| `cluster_host_tag_path` | `/etc/bluebanquise/tags` | Directory the two marker files are written into |
| `cluster_host_tag_inventory_checksum` | *(none - required)* | The inventory checksum to record. No default on purpose: the role asserts it is defined rather than silently writing an empty tag |
